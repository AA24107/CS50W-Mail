# Mail 
### Project 3


## Overview

A single-page email client built with Django and JavaScript, supporting sending, receiving, archiving, and replying to emails without page reloads.

Built as part of Harvard’s CS50 Web Programming with Python and JavaScript course.


## Features

* Inbox, Sent, and Archive mailboxes
* Compose and send emails
* View individual emails
* Mark emails as read automatically
* Archive and unarchive emails
* Reply to emails with pre-filled fields
  - Automatically fills:
    * Recipient
    * Subject (`Re:` handling)
    * Email body with original message


## Key Concepts

* JavaScript DOM manipulation
* Event-driven programming
* Fetch API for asynchronous requests
* Handling different HTTP methods (`GET`, `POST`, `PUT`)
* Dynamic UI updates without page reloads
* Managing application state through frontend logic


## Technologies Used

* Python (Django)
* JavaScript (Vanilla JS)
* HTML & CSS
* SQLite (default Django database)


## Notes

Focus on frontend logic, asynchronous communication, and dynamic UI updates rather than visual design.
